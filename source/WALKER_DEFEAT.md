# Siege Walker defeat by weapon destruction — revision 225

The Siege Walker dies when all four existing weapon modules are destroyed: beam cannon (1,800 durability), rocket pod (1,600), plasma cannon (1,800), and eye emitters (700). No additional hull/reactor kill is required. Each can be the final weapon. The boss bar now represents their combined 5,900 durability and is labelled WEAPONS. Existing individual weapon status indicators remain. If only the eyes survive after the main arsenal is disabled, the status reads EYE EMITTERS REMAIN.

`WalkerWeapons.health`, `.maxHealth` and `.remaining` expose the totals. `SiegeWalker.modifyDamage` routes incoming combat damage through the existing `damageWeapon`/part-durability logic and returns only the applied weapon damage to `UnitDamage`. The old post-damage callback is removed to avoid double damage. The last module returns the remaining boss health to ensure exact defeat even with fractional damage. Body/hull hits and unlocated global damage do not reduce defeat progress. Existing untagged splash can wear a module only when its impact is beside that module; overkill on one module does not spill into others.

The normal `UnitDamage` zero-health/disable route owns death, so the final break triggers the existing explosion, fall and 18-part smoking physical wreck exactly once. Previously detached weapon pieces are reused. Pending weapon preparations stop through the existing mount/death/arsenal gates; ordnance already launched keeps its existing flight behavior. Reset restores all module durability, attachments, health and attack grace. ARGUS, Bastion and smaller robot health/damage systems are unchanged.

CPU allies aim at surviving weapon centres rather than an invulnerable torso. This uses the existing aim-point hook; player aiming and aim assistance are unchanged. Public tuning remains in `WALKER_WEAPONS`, and Walker diagnostics include `defeatCondition: all-weapons` and `remainingWeapons`.

Validation: `QA/walker-defeat-condition-test.mjs` tests every final-weapon choice, large hull hits, partial damage, 1HP final-module survival, overkill, CPU aim points, exactly one defeat, 18 wrecks and reset. Updated `QA/walker-weapons-test.mjs` checks precise direct/blast part damage, independent module breaks, attack cancellation and all surviving arsenal combinations at multiple frame rates. `QA/walker-weapons-browser.cjs` exercises real desktop/touch lightning input against each weapon, shared hero/projectile adapters, exact health updates, no hull damage, final-weapon death, HUD and rebuild in battle/evacuation scenes. Gait, cannon tracking and robot-death tests pass. Death-effect fixtures now destroy the required modules before checking collapse; existing body-only debug kill shortcuts intentionally no longer kill this boss. Physical-phone FPS/thermal performance remains unmeasured.
